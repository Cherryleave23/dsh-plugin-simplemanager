# 插件管家 v0.1.1-rc.2（适配内核 v0.1.1-rc.2）

> 版本号 `0.1.1-rc.2` 与 DSH 官方内核版本一一对应，不因功能增补另开新版本号。

## 本版变更（同版本号覆盖更新，取代 8/22 旧快照）

- **重载前端预检普适化**：预检名单扩展到 `active` / `pending` / `loading` / `failed` 状态，并排除 `@deepseek-ai/*` 官方核心插件（避免沙箱假阳性）；对注册的界面组件做**渲染挂载探测**，准确拦下「热注入成功、但一刷新界面就崩」的插件。
- **P-043 失败即中止**：临时加载时依赖安装失败立即停止装配并清理，不再加载出「半挂」的插件实例。
- **P-044 先断开再拆除**：卸载时先把插件在运行期连入的路由 / 服务安全解绑，再移除装配登记，修复同类插件「热装 → 卸载 → 再热装」时的 `webserver: duplicate prefix route` 冲突。
- **复制报告**：重载前预检发现风险时，风险弹窗新增「⧉ 复制报告」一键拷贝，方便携带完整分步根因去插件处修改。

## 附件

- `dsh-plugin-simplemanager-0.1.1-rc.2.zip`：运行必需文件（含 `lib/` 编译产物），供本地 `dsh plugin add "file:...zip"` 或解压安装。

## npm 镜像

因 npm 不允许覆盖已发布的 `0.1.1-rc.2`，故含复制功能的同一内容额外以 **`dsh-plugin-simplemanager@0.1.1-rc.2-v1`** 发布到 npm（`latest` dist-tag 指向它），二者代码一致、仅版本号后缀 `-v1` 以示为 rc.2 内核适配的修订镜像。
